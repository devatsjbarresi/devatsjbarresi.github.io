<h1 align="center">ShowSquid Advanced Mode</h1>

---

## What Advanced Mode Is For

Advanced mode exposes the full protocol surface and option panes so you can tune ShowSquid behavior in more detail.

## How To Access

- Open ShowSquid.
- Go to _View > Level_.
- Switch to **Advanced**.

## What Changes in Advanced

- More protocol and option controls are visible.
- Additional setup properties for protocol groups are available.
- Previously used advanced selections are restored.

## Suggested Use Pattern

1. Start in Essential for quick operation.
2. Switch to Advanced when deeper protocol configuration is needed.
3. Return to Essential when running routine workflows.
