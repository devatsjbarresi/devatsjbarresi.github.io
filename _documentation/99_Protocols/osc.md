<h1 align="center">OSC</h1>

---

OSC (Open Sound Control) is commonly used for show control, media servers, consoles, and other entertainment control workflows.

ShowShark recognises OSC traffic and exposes message addresses and values where possible, including values that can be tracked with [Watchers](/docs/watchers/).

Use this page when checking that OSC messages are present in a capture and that expected address patterns are being sent.
